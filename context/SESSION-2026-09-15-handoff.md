Решения по ходу (не из плана):
- **Тело целиком — от 100 dp, а не от 64.** На картинках фигурка 64–96 — мелкое
  лицо над туловищем; в шапках и карточках голова читается лучше. `FULL_BODY_FROM`.
- **Персонаж — по профилю, а не по `useUIMode()`.** Родительская зона принудительно
  `teen`, но персонаж шестилетки там остаётся медвежонком.
- **Без движения по умолчанию меньше 48 dp** (пузыри чата, аватары) — `still ?? low`.
  В шапке «Говорить» `still={false}`, чтобы рот двигался.
- `ReactingPet.react('thinking')` из плана не добавлен: экраны передают `mood`.

Цвета: у шалфея щёки были жёлтыми, у розы сливались с шерстью — подобраны заново.

## Ловушки сессии

16. **Память машины.** Параллельно работает другой проект владельца (`nova`: ~12
    NestJS `--watch` и две Java по 1 ГБ) — занято ~13 из 15,6 ГБ, своп в ходу.
    Во время дев-сервера и статического веб-экспорта Metro сессия Claude дважды
    обрывалась (фоновые задачи «не завершились до конца сессии»). Вероятнее всего,
    это нехватка памяти (журнал ядра не смотрел) — и, возможно, та же причина, что
    у ловушки 15. Что помогло: одна сборка Metro за раз,
    `--max-workers 2` и `NODE_OPTIONS=--max-old-space-size=1800` (упадёт сам Metro,
    а не всё); веб — дев-сервером (`expo start --web`), не `expo export --platform
    web` (тот собирает ещё и серверный рендер).
17. **`eas update --skip-bundler --platform android`** публикует уже собранный
    `dist` — второй прогон Metro не нужен. `dist` перед этим проверять грепом на
    адрес API (ловушка из `RELEASE.md` §7a).
18. **Headless Chrome снова открывает http** (ловушка 14), если запускать сам
    бинарь `/opt/google/chrome/chrome`, а не обёртку `google-chrome`: тогда
    `kill` действительно его останавливает. Скрипт — `shots.mjs` из приложения к
    прошлому handoff, плюс `eval` и `Page.handleJavaScriptDialog`.
19. **Снимок «всей страницы» через увеличение окна даёт пустой кадр** на экранах с
    `ScrollView` — прокручивать сам прокручиваемый `div` (`scrollTop`) и снимать
    по частям.
20. **`aria-label` микрофона — на языке обучения** (`Tap to talk` при английском),
    а не интерфейса: искать кнопку по нему.
21. Типы маршрутов (`.expo/types`) обновляются только при `expo start`: новый
    маршрут `/dev/mascot` в `router.push` пока через `as any`.
22. Правка `Icon.tsx` скриптом по подстроке `lucide-react-native/icons/` задела
    комментарий в шапке файла — искать строки `import … from`, а не подстроку.

23. **Служебные символы в команде.** Строка `'\u0001'` в коде, который передаётся
    через heredoc, ломает вызов Bash-инструмента («control characters»). В таких
    местах собирать символ кодом (`String.fromCharCode(1)`) или писать файл
    инструментом записи.
24. **Дев-сервер с `CI=1` не следит за файлами** («reloads are disabled»): после
    правок снимки показывают старый код. Перезапускать сервер перед повторными
    снимками.
