# Söz/Honeybear — Рыночный дизайн-анализ и рекомендации (2026-07-03)

> Источники: (A) веб-исследование дизайна/UX конкурентов — Duolingo + Duolingo ABC, Lingokids,
> Buddy.ai, Novakid, Khan Academy Kids, Speak/ELSA/TalkPal + тренды 2025–2026;
> (B) инвентаризация всех наших экранов (home, talk, day-plan, complete, streak,
> achievements, pet-room, bobo-house, progress, paywall, parent, onboarding, HBPet).
> Итог: что ОСТАВИТЬ, что ДОБАВИТЬ, что ИЗМЕНИТЬ — с приоритетами и привязкой к экранам.

---

## ЧАСТЬ 1 — ВЕРДИКТ: ЧТО ОСТАВИТЬ (подтверждено рынком, не трогать)

| Наше решение | Подтверждение рынком |
|---|---|
| **Path-as-home** (зигзаг-путь, миры) | Золотой стандарт: Duolingo перешёл на единый путь в 2022, Duolingo ABC — карта города. Линейный путь снимает паралич выбора. |
| **Claymorphism / кремовая палитра / Fredoka** | Официально «стиль детских приложений 2025–2026» (Hype4, UI-гайды). Мы точно в тренде. |
| **Питомец с памятью (memory_threads)** | Duolingo Video Call с Lily «помнит прошлые разговоры» — премиум-фича их топ-тарифа. У нас это уже есть — конкурентное преимущество. |
| **PIN-гейт + разделение контуров ребёнок/родитель** | Норма рынка (ABC, Lingokids, Khan Kids). |
| **Возрастной сплит 5–10 / 11–16** | Подтверждён провалом Lingokids на 7–8-летних («2–8 одним интерфейсом» не работает) и трендами (tweens хотят «взрослый» UI). |
| **Честный триал 7 дней без карты** | Главная тема НЕГАТИВА у ВСЕХ конкурентов — хищнический биллинг (Buddy.ai safety score 33.5/100, ELSA, Novakid). Наш честный триал — не этика, а маркетинг. |
| **Прогрессивный AI-куррикулум (Phase 27)** | Второй по частоте негатив у Buddy.ai — «мелкий, повторяющийся контент». Наш ответ уже построен. |
| **Push-to-talk** | Buddy.ai и все детские голосовые продукты используют управляемый ввод, не open-mic. |

## ЧАСТЬ 2 — ЧТО ДОБАВИТЬ (гэпы против рынка)

### P1 — прямо в открытую задачу «флагманская полировка home/talk»

1. **Видимые состояния голосового UI в `talk.tsx`** — волновая анимация / индикатор уровня микрофона при записи. Отсутствие анимации «слушаю» — жалоба №1 на Speak; у нас её тоже нет (только статус-точка в шапке). Ребёнок должен ВИДЕТЬ, что его слышат.
2. **Реакция персонажа = награда.** У Duolingo микро-анимация Lily/Oscar на правильный ответ работает сильнее очков. Хани должен реагировать на каждый ответ ребёнка (радость/удивление/смех), а не только на завершение урока. Экраны: quiz, quest, talk.
3. **Разговор с целями-чеклистом (для 11–16)** — паттерн Speak: ролеплей с 3 видимыми задачами («спроси цену», «поздоровайся»…), автозавершение при выполнении. Превращает страшный «открытый разговор» в игру с финишем. Экран: `topics.tsx` / talk-сценарии.
4. **Звуковой дизайн.** У нас НОЛЬ звуков (только haптика) — единственные в категории. Минимум: успех/ошибка/звёздочка/завершение урока + звук питомца при тапе.
5. **Счётчики, которые «считают».** Звёзды/статы появляются статично. Анимация подсчёта (+1…+12) — дешёвый прирост ощущения награды. Экраны: complete, home, progress.

### P2 — следующая волна

6. **Богаче idle у HBPet.** Сейчас: боб + дыхание + моргание + 4 эмоции. У Lily — 64 комбинации idle, чтобы не выглядело лупом. Добавить 3–4 жеста (потягивание, взгляд по сторонам, помахивание) + реакцию на тап. Долгосрочно — смотреть Rive.
7. **Смягчение стрика.** «Плачущий Duo» документированно вызывает тревожность у подростков. У нас: streak freeze активным по умолчанию, тексты «Хани скучал» вместо «ты всё потерял», guilt-пуши — никогда.
8. **Персистентность pet-room.** Статы (голод/любовь/энергия) сейчас локальные и сбрасываются — обесценивает заботу о питомце. Сохранять (сервер или AsyncStorage) + мягкий decay по времени.
9. **Анимация разблокировки значков** + модал с деталью условия. Сейчас значки появляются без момента праздника. Экраны: achievements, bobo-house.
10. **Видимая история чата** — talk очищается каждый раз, хотя сервер помнит threads. Показать «прошлый разговор» сверху = ребёнок видит, что Хани реально помнит (усиливает главный дифференциатор).

### P3 — позже / по решению основателя

11. **Сюжетная обёртка недели** — комикс/сценка между мирами (паттерн Novakid Game World, главы Buddy). Наши 4 мира — готовый каркас, не хватает нарратива-связки.
12. **Второй персонаж со вторым голосом** в сценах (паттерн Buddy + Sparkles) — ребёнок учится различать голоса, участвует в диалоге третьим.
13. **AI-отчёты родителю уровня Lingokids** («что прошёл, где буксует») — у нас каркас parent-summary уже есть, углубить.
14. **«Одна большая кнопка» для 5–7** — паттерн Khan Kids: минимум выбора, Хани ведёт. Наш Today-tab близок; для младшей группы убрать/спрятать быстрые ссылки.

## ЧАСТЬ 3 — ЧТО ИЗМЕНИТЬ / ПРОВЕРИТЬ

1. **Коррекция произношения — щадящая для ребёнка, строгая для родителя.** ELSA демотивирует даже носителей (строгий скоринг). Наш чип «🎯 Скажи чётче» — ок; точные проценты ребёнку не показывать, детальный разбор — в родительскую зону. Итог ошибок — в КОНЦЕ сессии (паттерн TalkPal «тьютор, который не перебивает»), что совпадает с нашим age-aware correction из Part C.
2. **Микро-дозировка урока.** Khan Kids: сегменты 3–5 минут → +50% completion. Наш урок ~15 мин — проверить, что внутри он разбит на короткие «сцены» с промежуточными наградами.
3. **Проверка каждой механики на «тапай, пока не сработает».** Главная содержательная критика Lingokids: игры на узнавание, а не припоминание. Аудит квиза/quest: можно ли пройти не думая?
4. **Разница «путь vs свободный выбор»** должна быть визуально очевидной (жалоба даже на Khan Kids): Path = главное, «Послушать/Поговорить/Песни» = явно маркированная «игровая полка».

## ЧАСТЬ 4 — ГЭП-ЛИСТ ИЗ ИНВЕНТАРИЗАЦИИ НАШИХ ЭКРАНОВ (13 пунктов)

1. Нет звуков нигде (только haptics)
2. Нет волновой анимации/уровня микрофона при записи (talk)
3. HBPet: только 4 эмоции, нет жестов, нет реакции на тап
4. Счётчики статичны (не «считают»)
5. Pet-room статы не персистятся между сессиями
6. История чата не сохраняется между сессиями
7. Нет анимации разблокировки значков; нет модалов с условиями
8. bobo-house — ноль интерактивности и touch feedback
9. Текущий день в календаре стрика слабо различим (только border)
10. Нет skeleton-состояний на тяжёлых экранах
11. Нет swipe/long-press жестов вообще (только tap)
12. Онбординг: нет превью питомца выбранным цветом на шаге выбора; нет back на части шагов
13. Paywall: sparkles статичны, нет сравнения планов

## ЧАСТЬ 5 — ПОЛНЫЙ РЫНОЧНЫЙ ОТЧЁТ (сырьё)

### Duolingo (основное) + Duolingo ABC
- **Duolingo:** плоская яркая иллюстрация, «baby schema»-персонажи (большие глаза → опекающая реакция). С 2022 — единый вертикальный путь, золотая текущая ячейка. Duo — система эмоциональных состояний (радость/грусть/фрустрация/«умирающий» стрик). Персонажи дают микро-анимации-награды за правильный ответ. **Video Call с Lily:** Rive state machine, 8 анимаций головы × 8 тела = 64+ вариаций idle; AI помнит прошлые разговоры. Онбординг ~7 шагов до регистрации. **Критика:** стрик-тревожность у подростков, guilt-пуши, «погоня за XP» вместо обучения.
- **Duolingo ABC (3–8):** домашний экран — карта города (здание = набор уроков). Онбординг: ребёнок первым делом учится писать своё имя. Родительский гейт — «введи число словами». Без рекламы и покупок — главный источник доверия.

### Lingokids (2–8)
Яркая 2D-мультяшность, ансамбль персонажей как медиа-бренд (мерч, Lingokids Universe). Домашний экран — контент-хаб с поиском (НЕ путь). Parents Area: AI-отчёты. Paywall $14.99/мес, выручка ~$3M/мес. **Критика:** перестимуляция («анимации затмевают обучение»), игры на узнавание а не припоминание, слабый контент для 7–8 лет, жалобы на триал/списания.

### Buddy.ai (ближайший конкурент)
3D-робот Buddy в каждой игре + второй персонаж Sparkles (два голоса в сцене). Собственная ASR на 11 000+ часов детской речи. Урок из 4 частей: разминка → подача → игровая практика → применение. Главы-истории дают контекст. **Критика (фатальная):** JustUseApp safety score 33.5/100 — «пустой» триал, карта до триала, списания после отмены, мелкий повторяющийся контент, нет грамматики. 20M учеников/год = спрос на «голосового AI-друга» доказан; репутацию убила монетизация.

### Novakid (4–12)
Гибрид: живые уроки + Game World (комикс-истории, мини-игры, аватар, звёзды, CEFR). Trustpilot 4.4–4.9. **Критика:** не UI, а сервис — саппорт, двойные списания, автопродление.

### Khan Academy Kids (2–8)
Kodi Bear — проводник + 4 персонажа = навигационные категории (персонаж на домен). Домашний экран: одна большая кнопка Play (guided adaptive path) + отдельная библиотека. Уроки 3–5 минут → +50% completion. Бесплатно, офлайн — эталон доверия. **Критика мягкая:** разница guided/библиотека неочевидна.

### Speak / ELSA / TalkPal (старшие, голосовой UX)
- **Speak:** ролеплей со списком из 3 задач, разговор завершается сам; Free Talk 3–5 мин. **Критика:** нет анимации «слушаю», криптичные кнопки, AI заканчивает каждую реплику вопросом → «допрос».
- **ELSA:** пофонемная цветовая кодировка произношения (красный/жёлтый/зелёный) — эталон отображения коррекции. **Критика:** слишком строгий скоринг (носители ~80% — демотивация), сброс прогресса за пейвол, списания без согласия.
- **TalkPal:** 7 режимов (Chat, Roleplay, Debate, Character, Photo Mode, Call Mode); фидбек в конце сессии — «тьютор, который не перебивает». **Критика:** нет сводки паттернов ошибок, роботизированные голоса.

### Тренды 2025–2026
- Claymorphism — «официальный» стиль детских приложений (мы уже в нём).
- Rive-анимация персонажей (комбинаторные idle) — новый стандарт после Duolingo Video Call.
- Apple Design Awards 2025: награждают сдержанность и связь с реальным миром (CapWords — язык через фото реальных предметов), НЕ максимальную стимуляцию.
- Возрастная вилка признана индустрией: 3–7 — крупные CTA и аудио-инструкции; tweens/teens — «интерфейс как у взрослых приложений».

### 12 выигрышных паттернов рынка
1. Один видимый путь вместо меню (Duolingo, ABC, Khan Kids)
2. Реакция персонажа = награда (Duolingo)
3. Живой idle: комбинаторика, не луп (Lily/Rive)
4. Персонаж с памятью и характером (Lily) — у нас уже есть, показывать явно
5. Разговор с целями-чеклистом (Speak)
6. Видимые состояния голосового интерфейса
7. Коррекция без перебивания + цветовая кодировка (ELSA/TalkPal)
8. Микро-уроки 3–5 минут (Khan Kids)
9. Сюжетная обёртка недели (Buddy, Novakid, ABC)
10. Два персонажа / два голоса в сцене (Buddy)
11. Радикальное разделение контуров + AI-отчёты родителю (ABC, Lingokids)
12. Возрастная вилка визуального языка (тренды, Duolingo для подростков)

### 8 анти-паттернов
1. Хищническая монетизация — репутационный убийца №1 всей категории
2. Стрик-давление и guilt-пуши на детях
3. Перестимуляция вместо обучения (Lingokids)
4. Пустой триал / контент-мелководье (Buddy)
5. Слишком строгий скоринг произношения (ELSA)
6. Один интерфейс на слишком широкий возраст
7. Немые состояния голосового UI (Speak)
8. Неочевидная разница «путь vs библиотека»
