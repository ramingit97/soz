## Контекст

2026-09-20 владелец посмотрел редизайн B0–B7 на сборке `f3eb38b0` и сказал: дизайн «очень простой, не подходит», не нравится учить два языка сразу, в разговоре мешает кнопка. По HTML-макетам в `context/mockups/` выбрано:

- английский по умолчанию, один язык на курс;
- разговор без кнопок.

Структура экранов (одно главное действие) остаётся — меняется визуальный слой на всех ~50 экранах. Всё уходит через EAS Update: отпечаток нативной части `1a02f268…` меняться не должен.

## Главная техническая трудность

Цвета сейчас — один статический объект `colors` (`src/theme/colors.ts`): **725 обращений в 71 файле**, почти все внутри `StyleSheet.create` на уровне модуля. Тёмный режим D так сделать нельзя: стоит затемнить фон, и несмигрированные экраны станут «тёмным по тёмному». Поэтому перевод цветов на палитру режима делается **одним шагом для всего приложения** (этап 1), а уже потом экраны перерисовываются по макетам. После этапа 1 всё приложение цельно выглядит в новых цветах в обоих режимах, хотя раскладка экранов ещё старая.

## Решения, которые принимаю в плане (можно отменить при согласовании)

1. **Акцент больше не зависит от цвета питомца.** Цвета интерфейса — из макетов (kid: фиолетовый + зелёная кнопка; teen: мятный + жёлтая кнопка). Выбранный ребёнком цвет по-прежнему красит самого Бобо. `useAccent()` сохраняет форму, но отдаёт акцент режима — ~30 вызовов не ломаются.
2. **Вкладка «Прогресс» переименовывается в «Путь»**: у детей карта островов, у взрослых «Программа». Цифры прежнего «Прогресса» (серия, звёзды, слова, уроки) — компактной полосой сверху, ссылки на серию/награды/альбом остаются.
3. **Родительская зона, вход, пейволл — в варианте D** (они уже принудительно `teen`). Онбординг до выбора профиля — в варианте C.
4. **Картинки слов в уроках остаются эмодзи**, но в рамке-наклейке из макета. Нарисованные иллюстрации на сотни слов — отдельная задача, в план не входит.
5. **«Показать перевод» и подсказка слова в разговоре D** требуют правки сервера (`/talk` сейчас их не отдаёт). Делается подэтапом 6b; интерфейс прячет эти элементы, пока поля не пришли. Выкладку API на Fly запускает владелец.
6. **Точность («92%»)** считается на клиенте за урок; в «Программе» вместо процентов по прошлым урокам — звёзды, пока сервер точность не хранит.
7. **Слабые телефоны (Galaxy A21s):** двигаются только Бобо и активный шаг; облака, мерцание звёзд, водопад выключены. Размытие «стекла» на Android заменяется полупрозрачной заливкой.
8. **Шрифт заголовков kid — M PLUS Rounded 1c** (800/900): проверен на `ə Ə ğ ı İ ş ç ö ü` и кириллицу. Подключается файлом `.ttf` из `@expo-google-fonts/m-plus-rounded-1c` (JS-зависимость, отпечаток не меняет — проверяется на этапе 1). Teen остаётся Onest, текст — Nunito.

## Этапы

Каждый этап делает оба режима сразу (экран один, стилей два), проходит проверку и отдельно уходит в `preview`. Владелец присылает скриншоты с A21s и широкого телефона; правки по ним — в тот же этап.

### Этап 0 — один язык (малый, независимый, первым)
- `app/learning-languages.tsx`: по умолчанию «Только английский», порядок: английский → русский → оба (без «рекомендуется»).
- `src/i18n/strings.ts` (ru/az): приветствие «учит английский в игре» вместо «два языка»; `app/welcome.tsx`.
- `src/components/home/HomeHeader.tsx`: переключатель EN/RU убрать с главного; у старых профилей с двумя языками выбор курса — строка «Курс» в `app/profile.tsx`.
- `STORE_METADATA.md`, `context/STORE_METADATA.md`: формулировки.

### Этап 1 — фундамент темы (весь вид приложения меняется сразу)
- Новый `src/theme/palettes.ts`: `PALETTES: Record<UIMode, Palette>` с теми же смысловыми ключами, что у `colors` (`ink`, `inkSoft`, `surface`, `surfaceBorder`, `bg`, `bgDeep`…) плюс роли из макетов: `cta/ctaEdge/ctaText`, `accent/accentSoft`, `highlight`, `success`, `error`, `glass`. Значения — из CSS-переменных макетов C и D.
- `src/theme/modeTokens.ts`: поле `c: Palette`, тени с оттенком режима, радиусы (kid 22–34, teen 16–22), нижняя «грань» кнопок. `useTheme()` отдаёт `c`.
- **Миграция `colors.*` → `t.c.*`** во всех 71 файле: скрипт оборачивает `StyleSheet.create` в `makeModeStyles((t) => …)`, дальше ошибки `tsc` показывают, где добавить `const styles = modeStyles[useUIMode()]` и `const { c } = useTheme()`. 50 сырых hex в `app/` и массивы градиентов — вручную.
- Базовые компоненты: `Text`, `HBButton` (kid: градиент-леденец, блик, грань; teen: жёлтая с гранью 4 px), `HBCard`, `HBChip`, `HBIconBox`, `HBBackButton`, `Field`, `ChoiceCard`, `InlineBanner`, `Skeleton`, `StepIndicator`, `BottomTabs` (kid: парящая лавандовая панель; teen: полоса `night-2`; «Путь» с иконкой карты).
- Фоны: `Screen`/`PaperBackground` → варианты `sky` (закат), `lavender` (урок), `night` (разговор), `party`; у teen плоский `#121A3A`. `StatusBar` светлый на тёмном.
- `app/_layout.tsx`: новый шрифт в `fontsReady`. `check-ui.mjs`: метрика «статический импорт `colors`», базовая линия → 0 к этапу 10.

### Этап 2 — Бобо и мир

- 6b, сервер (по желанию владельца): `/talk` отдаёт `translation` и `tip`; выкладку на Fly запускает владелец.
