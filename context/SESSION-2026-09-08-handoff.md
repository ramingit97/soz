## Принятые решения этой сессии

**Имя пакета `az.soz.app`** — зафиксировано в Play, изменению не подлежит никогда.
Отказались от `technology.cubics.soz`: `cubics.technology` не принадлежит владельцу.
Имя пакета к домену отношения не имеет, обратный DNS — просто соглашение.

не шлёт с gmail. До продакшена хватает `onboarding@resend.dev`, который доставляет
только на адрес самого аккаунта Resend. Страницы политики можно положить на
GitHub Pages. Домен станет обязательным перед закрытым тестом с 12 людьми:
тестировщики не получат ни восстановление пароля, ни кризисный алерт.

**Название:** на телефоне `Söz`, в листинге Play `Söz — язык с Хани`.
Язык листинга по умолчанию — русский.

**Регион Neon оставлен как есть** (осознанно, помечено как оптимизация).

## Три бага, найденных при первом деплое

Все три были латентными — типы зелёные, тесты зелёные, а прод не поднимался.

### 1. `JWT_SECRET` был dev-заглушкой
`apps/api/src/index.ts:51` специально отвергает значение `change-me-in-production`.
Машина перезапустилась 10 раз и сдалась. Сгенерирован настоящий, лежит в секретах Fly.

### 2. Не было `.dockerignore`
В билдер уезжал весь корень репозитория — 661 МБ, из них 657 МБ `node_modules`,
которые образ всё равно ставит сам через `pnpm install --frozen-lockfile`.
Контекст сборки: 661 МБ → 3.9 МБ. Заодно `.env` исключён явно.

### 3. Metro не мог разрешить импорты `shared-types`
**Самый важный.** `packages/shared-types` отдаётся сырым TypeScript
(`main: ./src/index.ts`, без сборки), и его файлы читают два тайпчекера с
несовместимыми требованиями:

- `apps/api` на `moduleResolution: NodeNext` — расширение `.js` **обязательно**,
  даже когда на диске `.ts` (иначе TS2835);
- Metro понимает `./language.js` буквально, ищет такой файл и роняет бандлинг.

Убрать расширения в пакете нельзя — пробовали, `apps/api` перестаёт компилироваться.
Развязано в `apps/mobile/metro.config.js`: `resolveRequest` сначала пробует обычную
резолюцию и только при неудаче отбрасывает `.js`. Порядок важен — настоящий
`.js`-файл, если он есть, побеждает.

**Почему не поймали раньше:** `pnpm typecheck` зелёный, а Metro в проверках не
участвует. Поломка лежала с 24 августа, с переезда streak в `shared-types`.
Первый же прогон бандлера её вскрыл.

**Вывод на будущее:** `pnpm typecheck && pnpm test` НЕ доказывает, что приложение
соберётся. Перед сборкой EAS прогонять локально:
```bash
cd apps/mobile && ../../node_modules/.bin/expo export --platform android
```
Это 1–2 минуты против 15 минут очереди EAS и «Unknown error» в ответ.

## Прочие правки

- **`eas.json`** — удалён `submit.production.ios`: пустые строки в `ascAppId` и
  `appleTeamId` роняли валидацию ВСЕЙ конфигурации, включая Android-команды.
  Заполнить заново при переходе на iOS.
- **`eas-cli@23.2.0`** переведён из `npx` в devDependency `apps/mobile`. npx
  распаковывал его в общий кеш `~/.npm/_npx`, где `is-docker` остался битым
  (`ERR_MODULE_NOT_FOUND`). Все команды в `RELEASE.md` переписаны.
- **`app.config.ts`** — `projectId` прописан значением, а не только из env:
  `.env` под gitignore, а EAS Build игнорируемые файлы не загружает, и на
  сборочном сервере id разрешился бы в пустую строку. Добавлен `owner`.
- **`fly.toml`** — `dockerfile` теперь `"Dockerfile"`: путь резолвится
  относительно самого `fly.toml`, а не рабочего каталога.
- **`safetyAlerts.integration.test.ts`** сделан герметичным. Тест молча
  полагался на ОТСУТСТВИЕ `RESEND_API_KEY` в окружении; после появления
  настоящего ключа Resend начал отвечать 422 на адреса `@example.com`.
  Ключ удаляется до загрузки `email.ts`, модуль тянется динамическим импортом.
- **`.gitignore`** — добавлен `.claude/settings.local.json`: в его allow-правилах
  лежали ключ ElevenLabs и пароль Neon открытым текстом. В коммиты не попал,
  вся история проверена на секреты и чиста.

## ВАЖНО при переезде на другой компьютер

`apps/api/.env` под gitignore и **вместе с репозиторием не приедет**. Без него
локальный API не поднимется.

Нужные переменные (значения — из дашбордов провайдеров либо перенести файл
руками через менеджер паролей):

```
OPENAI_API_KEY  DEEPGRAM_API_KEY  ELEVENLABS_API_KEY  ELEVENLABS_MODEL_ID
DATABASE_URL  JWT_SECRET  REVENUECAT_WEBHOOK_SECRET  RESEND_API_KEY
RESEND_FROM  RESEND_REPLY_TO  SAFETY_OPERATOR_EMAIL
```

`ELEVENLABS_VOICE_ID_EN` / `_RU` можно не заполнять — в `ai/env.ts:25` есть дефолт.
`REDIS_URL` не используется, Redis отложен.

Продовые значения уже лежат в секретах Fly и оттуда не читаются:
`flyctl secrets list -a soz-api` покажет только имена. Локальный `JWT_SECRET`
намеренно отличается от продового.

Что ещё придётся поставить заново на новой машине:

```bash
curl -fsSL https://fly.io/install.sh | sh     # flyctl → ~/.fly/bin
~/.fly/bin/flyctl auth login
corepack pnpm install
corepack pnpm --filter @soz/mobile exec eas login
```

## Отложено осознанно (не забыть, но и не блокер)

**Neon в us-east-1, Fly во Frankfurt.** Каждый запрос к базе — 99 мс на дорогу,
замерено на живом `/health/ready`. Один ход ребёнка делает несколько запросов
подряд. Neon не умеет менять регион существующего проекта, только новый проект.
Сейчас база пустая — переезд бесплатный; после тестировщиков это миграция
с даунтаймом.

**Прод и локальная разработка смотрят в ОДНУ базу.** Видно по логам миграции:
все таблицы уже существовали. Пока пользователей нет — терпимо. Когда появятся
тестировщики, любой локальный запуск начнёт писать в живую базу с их детьми.
Отдельный dev-проект в Neon решает это тем же действием, что и регион.

**Холодный старт Neon.** После простоя первый запрос к базе — 864 мс вместо 99
(замерено). Ребёнок почувствует на первом «привет» за день.

**Ключи в `.claude/settings.local.json`** лежат открытым текстом на машине.
В git не попали, но при переносе на другой компьютер файл не копировать.
