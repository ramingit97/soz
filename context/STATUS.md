## Что осталось — всё на стороне аккаунтов, не кода

Порядок по критическому пути:

1. **Play Console** — ждём верификацию. Потом: создать приложение
   (`az.soz.app`), анкета Families, Data safety, сервис-аккаунт для EAS.
2. **Домен** (~$10/год) — нужен для писем (Resend не шлёт с gmail) и страниц
   политики. Купить → сказать Claude → он подставит вместо `YOUR-DOMAIN`.
   Альтернатива для политики без домена: GitHub Pages.
3. **Тестировщики** — Google требует 12 человек с установленным приложением
   14 дней подряд (считает установку, не активность). Собирать 15–20 с Android
   и их gmail. Не удалять две недели.
4. **Аккаунты по 5–10 минут:** Fly.io, Neon, Resend (+ верификация домена),
   ElevenLabs (план Creator, $11 первый месяц), OpenAI (+$10), Deepgram ($200
   бесплатно), RevenueCat, Expo. Всё бесплатно кроме ElevenLabs и OpenAI.
5. Дальше строго по `RELEASE.md`: Neon → Resend → Fly deploy → RevenueCat →
   legal-страницы → Play Console → `eas build --profile preview` → тест на
   реальном Android → закрытый тест 14 дней → `eas submit`.

## Бюджет до релиза (замерено на реальном пайплайне)

Один ход ребёнка ≈ $0.0013 (LLM + STT + классификатор) + ~40 кредитов ElevenLabs.
Голос — единственная существенная статья.

| Сценарий | Сумма |
|---|---|
| 15 тестировщиков, умеренно (3–5 активных детей) | **≈ $50–60** |
| 20 тестировщиков, все активно каждый день | ≈ $150–165 |

Разбивка: Play $25 · ElevenLabs $11–22 · OpenAI $10 · Fly $3.32/мес · остальное $0.
Активный ребёнок весь месяц ≈ $2.5 при подписке $4.99 — сходится, но без запаса.
